# RCM Analytics Platform

End-to-end analytics project for a synthetic healthcare Revenue Cycle Management (RCM) company that processes insurance claims for hospitals in Egypt, KSA, UAE and Jordan.

> All data is synthetic and generated by `src/generate_data.py` with a fixed seed, so anyone can reproduce it exactly.

## Business question
Where is revenue lost in the claims lifecycle, which payers and root causes drive it, and which interventions recover the most money?

## Architecture
```
CSV files (raw) -> SQL Server staging -> clean views -> star schema -> Power BI (RLS) -> analysis and recommendations
```

## Repository structure
```
data/        raw CSV files and data notes
src/         synthetic data generator (Python)
sql/         staging, cleaning, warehouse, data quality, ETL procedures, performance
powerbi/     report, DAX measures and screenshots
python/      denial prediction model (optional phase)
docs/        data dictionary, KPI definitions, architecture
```

## Quick start
```bash
pip install numpy pandas
python src/generate_data.py
```
