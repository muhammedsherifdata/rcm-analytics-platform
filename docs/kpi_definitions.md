# KPI definitions

| KPI | Definition |
|---|---|
| Denial rate | denied claims / settled claims (Paid + Denied, excluding Pending) |
| Clean claim rate | claims with no eligibility, authorization, coding or timely-filing problem / total claims |
| Days in AR (simplified) | payment_date - submission_date |
| Net collection rate | paid amount / (billed amount - contractual adjustments) |
| Appeal success rate | appeals overturned / appeals decided |
